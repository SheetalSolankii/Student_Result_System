# Student Result Management System

A web-based Student Result Management System developed using PHP and MySQL.

## Features

- Admin Login
- Add Student Result
- Update Result
- Delete Student Record
- Search Result by Roll Number
- Printable Report Card
- Dashboard Analytics

## Technologies Used

Frontend:
- HTML
- CSS
- Bootstrap
- JavaScript

Backend:
- PHP

Database:
- MySQL

## How to Run

1. Install XAMPP
2. Start Apache and MySQL
3. Import database.sql
4. Place project inside htdocs
5. Open:
http://localhost/Student_Result_System
